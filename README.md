<h1 align="center">osTicket Post-Installation Configuration </h1>

<p>
This project demonstrates the post-installation configuration process of the open-source help desk ticketing system <strong>osTicket</strong>. The lab includes configuring roles, departments, teams, agents, users, and SLAs within the osTicket admin panel.
</p>

---

<h2>Project Summary</h2>

<p>
This tutorial walks through the essential post-installation configuration steps required to properly manage and organize an osTicket help desk environment. The project demonstrates how administrators can configure user roles, departments, support teams, and ticket settings to create a functional ticketing system.
</p>

<h3>Languages Used</h3>

- PowerShell

<h3>Environments Used</h3>

- Microsoft Azure (Virtual Machines)
- Windows 10 (21H2)
- Windows 11

<h3>Technologies / Applications Used</h3>

- osTicket
- Microsoft Azure
- Remote Desktop
- Internet Information Services (IIS)

---

<h2>Post-Install Configuration Objectives</h2>

- Configure Roles and Permissions
- Create Departments
- Configure Support Teams
- Create Agents and Users
- Configure SLA Plans
- Create Help Topics

---

<h2>Configuration Steps</h2>

<h3>Step 1: Configure Roles and Permissions</h3>

<p align="center">
  <img src="https://i.imgur.com/DJmEXEB.png" height="80%" width="80%" alt="Roles Configuration"/>
</p>

<p>
Roles are configured within the osTicket admin panel to define the permissions assigned to support agents. This allows administrators to control access levels and determine what actions agents can perform within the ticketing system.
</p>

<br />

<h3>Step 2: Create Departments and Teams</h3>

<p align="center">
  <img src="https://i.imgur.com/DJmEXEB.png" height="80%" width="80%" alt="Departments and Teams"/>
</p>

<p>
Departments and teams are created to organize support staff and manage ticket assignments efficiently. This setup helps separate responsibilities between different support groups such as SysAdmins, Networking, and Help Desk teams.
</p>

<br />

<h3>Step 3: Create Agents and Users</h3>

<p align="center">
  <img src="https://i.imgur.com/DJmEXEB.png" height="80%" width="80%" alt="Agents and Users"/>
</p>

<p>
Support agents and end users are added to the system through the osTicket admin and agent panels. Agents are responsible for resolving tickets, while users can create and manage support requests through the help desk portal.
</p>

<br />

<h3>Step 4: Configure SLA Plans and Help Topics</h3>

<p align="center">
  <img src="https://i.imgur.com/DJmEXEB.png" height="80%" width="80%" alt="SLA Plans"/>
</p>

<p>
Service Level Agreement (SLA) plans are configured to define ticket response and resolution times. Help topics are also created to categorize incoming tickets and improve ticket routing throughout the support environment.
</p>

<br />

---

<h2>Conclusion</h2>

<p>
This project successfully demonstrated the post-installation configuration of osTicket within a Windows environment. The lab provided hands-on experience managing roles, departments, users, and SLA configurations commonly used in IT support and help desk environments.
</p>
